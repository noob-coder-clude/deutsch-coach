# Deutsch Coach (Android)

دستیار/مربی یادگیری آلمانی — **نه درس‌دهنده**. فقط متد (میشل توماس / دویچ‌ماخت)، بدون محتوای دوره.

## نسخه ۱ (فاز ۱)

سه تب:

- **مربی:** چک‌لیست روزانه + قوانین متد
- **کجای مسیر:** وقتی گیج شدی، فاز/قدم بعدی
- **تمرین:** جمله‌های سخت خودت (بدون نمره‌دهی کلمه‌به‌کلمه)

minSdk 26 / targetSdk 34. بدون اینترنت. پلی‌استور-سیف.

## بیلد

GitHub Actions روی هر پوش `assembleDebug` می‌زند و APK را به‌عنوان artifact می‌گذارد.

محلی:

```
./gradlew assembleDebug
```
